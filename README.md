### 👨‍💻 About me

I'm a software engineer with 10+ years of experience building backend and distributed systems across **banking, cybersecurity, IoT and broadcasting**.

I particularly enjoy working on systems where scale, reliability and architecture actually matter.

- 🔨 Backend & distributed systems
- ⚡ Event-driven architecture and high-throughput data processing
- ☁️ Cloud platforms and infrastructure
- 🧭 Technical architecture and engineering leadership
- 🔍 Observability, reliability and production engineering
- 🇳🇱 Based in Maastricht, Netherlands

Most of my professional code lives in private company repositories, so you'll find a mixture of side projects, experiments and older projects here.
